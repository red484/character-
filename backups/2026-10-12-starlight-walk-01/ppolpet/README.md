# 뽈뽈펫

웹(공방)에서 머리가 몸의 3배인 초SD 비닐 피규어 동물 캐릭터(three.js)를 꾸미고 **[바탕화면에 적용하기]**를 누르면, 데스크톱 앱에서 그 캐릭터가 작업표시줄 위를 뽈뽈 걸어다니는 배포물.

```
shared/pet-render.js   초SD 피규어 캐릭터 만들기·움직임 (웹이랑 앱이 같이 씀, three.js r149)
web/maker.src.html     공방 페이지 원본
docs/index.html        GitHub Pages에 올라가는 완성본 (build-web.js가 만듦)
app/                   데스크톱 앱 (Electron, 맥·윈도우)
.github/workflows/     태그 올리면 맥 .dmg / 윈도우 .exe 자동 빌드
```

## 캐릭터가 공방에서 앱으로 가는 방법 3가지
1. **앱으로 바로 보내기**: `ppolpet://add?c=코드` 링크. 앱이 설치돼 있으면 바로 열림
2. **캐릭터 파일 (.ppol)**: 더블클릭하거나 바탕화면 캐릭터 위로 끌어다 놓기
3. **코드 복사**: 바탕화면 캐릭터 우클릭 → *복사한 코드로 데려오기*

꺼내놓은 캐릭터는 저장돼서 앱을 다시 켜도 그대로 나와요. 친구 코드를 받으면 친구 캐릭터도 같이 돌아다님 (최대 12마리).

## 배포 순서
1. GitHub에 `ppolpet` 레포를 만들고 이 폴더를 그대로 올리기
2. **Settings → Pages** 에서 `main` 브랜치의 `/docs` 폴더로 설정 → 공방 주소가 생김 (예: `https://아이디.github.io/ppolpet/`)
3. `app/main.js` 맨 위의 `MAKER_URL`을 그 주소로 바꾸기
4. 태그 올리기: `git tag v1.0.0 && git push --tags` → Actions가 돌고 **Releases**에 `.dmg`, `.exe`가 올라옴
5. `web/maker.src.html` 의 `DOWNLOADS`에 Releases 파일 주소 넣고 `node build-web.js` → 커밋

공방 페이지를 고치면 항상 `node build-web.js` 한 번 돌리고 커밋하기 (앱 쪽 `pet-render.js`도 같이 갱신됨).

## 내 컴퓨터에서 바로 돌려보기
[Node.js](https://nodejs.org) 설치 후:
```bash
node build-web.js
cd app
npm install
npm start
```

## 받는 사람한테 알려줄 것
- **맥**: 서명 안 된 앱이라 처음엔 "확인되지 않은 개발자" 경고가 떠요. 앱을 **우클릭 → 열기**로 한 번 열면 다음부터 그냥 열림.
- **윈도우**: "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**.
- 앱은 독/작업표시줄에 안 보여요. 끌 때는 캐릭터 우클릭 → **전부 종료**.
- 우클릭 메뉴에 **컴퓨터 켤 때 같이 켜기**도 있음.

## 꾸밀 수 있는 것
귀 7 · 꼬리 5 · 눈 8 · 입 7 · 무늬 5 · 소품 13(여러 개) · 부위별 색 9 · 코/수염/볼터치/배/양말/외곽선 on·off
슬라이더 10개: 머리 크기·가로, 눈 크기·사이·높이, 입 높이, 볼터치 크기, 귀 크기·벌어짐, 몸 크기 (`TUNE`에서 범위 조절)
행동: 걷기(종종걸음·뒤뚱) · 가만히 · 두리번 · 콩콩 · 인사 · 졸기 · 잡힘 · 떨어짐
파츠 추가는 `shared/pet-render.js` 의 `OPTIONS`와 `buildCharacter` 안의 해당 부분(귀·꼬리·눈·입·소품)에 넣으면 됨.
비율은 `RX/RY/RZ`(머리 크기)·`HEAD_Y`(머리 높이)와 `buildCharacter`의 몸·발·팔 크기로 정함. 머리 모양은 `headShape`.
얼굴은 `drawHead`가 머리 텍스처에 기호처럼 그림 (눈·입 모양 추가는 여기).


## 2026-10-08 말랑 공방 업데이트

- 귀를 머리 윗부분으로 옮기고 눈·입 크기, 볼 실루엣, 파스텔 조명, 수염을 정리했습니다.
- 추천 친구 6종, 이름 바로 짓기, 되돌리기/다시 하기, 앞·옆·뒷모습, 모션 멈춤을 제공합니다.
- 성격 4종: 느긋이, 장난꾸러기, 수줍이, 애교쟁이. 실제 걸음 속도, 탄력과 행동 빈도가 달라집니다.
- 성격·관계에서 친구/가족/짝꿍을 선택하면 상대가 생깁니다. ‘내 친구 꾸미기’와 ‘상대 친구 꾸미기’로 각각 외형과 성격을 바꿉니다.
- ‘둘이 같이 놀기’는 접근 → 인사 → 관계별 행동으로 이어집니다. 친구는 콩콩, 가족은 함께 쉬기, 짝꿍은 볼 부비기입니다. 수줍은 친구는 작은 인사를 합니다.
- 알아서 놀기를 켜면 자동으로 행동합니다. 시스템의 동작 줄이기 설정에서는 처음에 멈춰 있습니다.
- 이미지에는 두 친구가 함께 나오며, 코드와 .ppol 파일은 두 친구 및 관계를 함께 담습니다. 기존 v1 캐릭터 코드도 읽습니다.
- 한 캐릭터에 지정할 수 있는 상대는 현재 1명입니다. 여러 캐릭터 사이의 관계 그래프는 이번 범위에 포함하지 않습니다.
- 앱은 관계가 포함된 캐릭터를 받으면 두 친구를 생성하며, 같은 화면에서 서로 다가가 상호작용합니다. 앱을 재시작해도 연결을 유지합니다.

### 확인한 항목

`node tests/behavior.test.js` — 코드 호환성·성격별 행동 비율·관계별 행동·짝 생성/접근/쿨다운/드래그/재시작 복원 로직·웹 스크립트 문법·렌더러 동기화.
브라우저에서 추천/파츠 변경, 되돌리기/다시 하기, 체형 조절, 상대 생성 및 별도 이름 편집, 관계 저장/복원, 완성 이미지 렌더링, 모바일 너비를 확인했습니다.
Electron 창 생성과 동작 로직은 모의 창으로 검증했습니다. 실제 macOS/Windows 설치본의 실행·프로토콜 등록·다중 모니터 동작은 아직 검증하지 않았습니다. 앱 배포 주소와 설치 파일은 기존 프로젝트처럼 별도로 설정/빌드해야 합니다.
웹 공방은 `docs/index.html`을 브라우저에서 열어 볼 수 있습니다. Three.js와 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다.


### 추가 참고 이미지 반영

처음 민트 배경 참고 이미지에 맞춘 가로로 살짝 넓은 머리와 완만하게 눌린 턱, 큼직한 기호 눈(の/반달/동글 링), も 입, 큰 등 리본을 추가·조정했습니다. ‘젤리 앉기’는 눈을 감지 않고 앞쪽으로 발바닥 젤리를 보여 줍니다. 점프와 인사는 고개 기울임도 함께 표현합니다. 기본 미리보기와 추천 이미지는 앉은 자세이며, ‘알아서 놀기’를 누르면 성격별 자동 행동으로 전환됩니다.


### 걷기 수정
걷는 동안 몸 전체가 뜨거나 늘어나는 효과를 제거했습니다. 한 발을 지지하는 시간이 보행 주기의 60%가 되도록 짧은 보폭을 만들고, 팔·머리·귀의 흔들림을 줄였습니다. 앉은 자세에서 발이 즉시 꺾이지 않도록 전환을 완화하고, 데스크톱 이동 속도도 줄였습니다.
