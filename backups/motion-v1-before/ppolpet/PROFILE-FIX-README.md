# 별빛냥 측면 얼굴 직접 수정 (2026-10-13)

이 패치는 뿔뿔펫의 기존 Three.js `starlight-v1` 모델을 **다시 만들지 않습니다**. 원본 `ppolpet.zip`의 머리, 귀, 몸, 보행 및 6종 프리셋 설정을 유지합니다.

## 변경

- 공통 렌더러: `shared/pet-render.js`
- Electron 복사본: `app/pet-render.js` (`node build-web.js`가 자동 동기화)
- 기존 측면 `frozenFace()`가 `sideExpression()`을 호출해 카메라 화면에 링을 다시 투영하는 동작을 제거했습니다.
- 정면 0°와 45°는 기존 `drawHead()`를 그대로 사용합니다.
- 48~78°에서 **기존 링 하나만** 뒤쪽 볼로 자연스럽게 이동시키며, 66~87°에 걸쳐 작은 검은 측면 눈과 코끝 점을 머리 UV 위에 나타냅니다. 뒷면으로 회전하면 점차 사라집니다.
- 머리 메시를 회전시키는 **실제 Three.js 3D 캐릭터**는 그대로입니다. 다만 서로 충돌하는 정면/측면 얼굴 연출을 위해 시야각에 따라 얼굴의 UV 그래픽을 점진적으로 보정합니다. *카메라와 완전히 독립적인 하나의 고정 텍스처는 아닙니다*. 방향별 PNG나 새로운 3D 모델로 바꾸는 방식도 아닙니다.
- 옛 검수 실험용 `sideExpression()` 코드는 남겼지만 **실제 공방의 기본 얼굴 경로에서는 사용하지 않습니다**.

## 검수

프로젝트 폴더에서 아래를 실행합니다.

```bash
node build-web.js
node tests/behavior.test.js
python3 -m http.server 8765
```

브라우저에서 `http://127.0.0.1:8765/docs/starlight-profile-fit.html`을 엽니다. 실제 Three.js 렌더로 이전 90°/수정 90°, 0°/45°/75°/90°/135°를 볼 수 있습니다. 슬라이더로 **측면 검은 눈, 코끝, 링과 볼터치**를 미세 조절하고 설정 JSON 또는 비교 이미지를 저장할 수 있습니다.

페이지가 빈 화면이면 `https://cdn.jsdelivr.net/npm/three@0.149.0/build/three.min.js`가 연결되는지 확인해주세요. 기존 프로젝트도 같은 CDN을 사용합니다.

## 테스트 범위와 주의점

- 정적 JS 구문, 프로젝트 빌드, 기존 행동 테스트, 0°/45°/90°/180° 보정 범위와 UV 질감 테스트를 통과했습니다.
- 작업 환경에는 Three.js CDN에 접속할 수 없어 **실제 WebGL의 최종 3D 렌더를 직접 눈으로 검수하지 못했습니다**. 검수 페이지에서 실제 브라우저 결과를 확인한 후 확정해주세요.
- 이번 수정은 얼굴 표현 문제만 처리했습니다. 원본 시트와 완전히 똑같은 모델을 보장하지 않으며, 3D 메시/리깅/기타 캐릭터 외형은 변경하지 않았습니다.
- 실패하면 수정본의 `shared/pet-render.js`를 원래 업로드한 ZIP의 같은 파일로 교체한 뒤 `node build-web.js`를 실행하면 복구할 수 있습니다.
