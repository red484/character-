# 측면 눈 표현 후보 — 승인 대기

사용자 최신 지시: 기존 정면/45도 링 눈, 새 코 유지. 75–90도 눈 중심/가시 형태 변경 허용.

- 기준 형상과 코: ../starlight-identity-fit/review-renderer.js 그대로. 이 단계에서 귀/머리/몸/발/꼬리/코 메시 형상 추가 변경 없음.
- 지난 실험의 링 가장자리 메시 제거.
- 0–45도: 원래 drawHead/frozenFace 링 눈 표현. 중복 캔버스 코는 제거하고 승인한 3D 코 사용.
- 45–75도: 같은 머리 재질에서 절차적 타원 마스크의 중심/가로 폭/채움/색을 smoothstep으로 연속 보정.
- 75–90도: 코보다 .105 모델 단위 뒤, .17 위에 세로 타원 중심. 해당 위치에 가장 가까운 실제 머리 UV를 탐색한 뒤 경도 반폭 .048 rad / 위도 반높이 .10 rad로 세로 타원 구성.
- 같은 머리의 로컬 좌표로 평가되어 표면의 가림과 조명 적용. 별도 측면 PNG, 카메라를 바라보는 눈판, 각도별 모델 교체 없음.
- 시점 의존 표현임을 페이지에 명시. 고정 눈 위치를 모든 각도에서 유지하는 물리적 모델이라고 주장하지 않음.
- 운영 renderer/presets, 다른 캐릭터/모션은 변경하지 않음.

검수: 0/45/75/90 비교, 얼굴 확대, 45–75도 5도 간격, 실제 드래그 및 연속 회전.
