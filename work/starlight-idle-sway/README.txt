별빛냥 좌우 갸웃 대기

현재는 기존 대기 이미지 첫 프레임으로 만든 연결된 2D 텍스처 메시 애니메이션. 새로운 Three.js 캐릭터/3D 모델 아님.
머리 y<=196은 강체 회전, 목 y196..232는 smoothstep 회전 가중치, y>=232 발은 완전히 고정. 얼굴을 따로 잘라 붙이지 않음. ±6도, 3.2초 사인 루프. UI 8개 샘플과 PNG 내보내기, 실제 재생은 연속.
이전 대기 코드/설정은 before-tilt/. assets/idle-sway-v1.png는 변경 없음. imagegen으로 만든 idle-tilt-v1.png는 검토 후 미사용(방향 순서 불일치). 프롬프트는 prompts/에 보존.
검증: 머리 두 점 거리와 발 고정 수치 검증, 브라우저 좌/우 포즈 및 재생, JS 모듈 구문 검사.
설정 재생성: python3 build-manifest.py
