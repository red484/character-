# 별빛냥 레퍼런스 정합 후보 — 승인 대기

운영 공통 renderer와 presets는 수정하지 않았음. 이 디렉터리는 독립적인 내부 검수 후보.
기존 기준: ../starlight-nose-review/before-renderer.js (원래 Three.js 모델).
reference.png는 사용자 첨부 원본 보존본.

## 구현
review-renderer.js reviewBuild 내부에서만 후보 생성.
- 앞중앙 Z 곡면만 국소 보정. X/Y, 귀, 몸통, 팔, 다리, 꼬리 유지.
- 레퍼런스 수동 중심 좌표를 실제 메시 Y/Z에 대응.
- 실제 UV 삼각형을 래스터화하여 검은 눈/노란 링/분홍 볼을 고정 텍스처로 한 번 생성.
- 작은 코는 실제 앞끝에 대부분 묻힌 얕은 3D 캡. 카메라별 이동 없음.
- 이전 view-dependent face 보정은 후보에서 실행하지 않음.

## 검증 및 한계
outputs/starlight-reference-fit/validation.json에 실측값.
500px 캔버스 기준 표면 표본 오차는 텍스처 중심의 이미지 검출 오차가 아님.
레퍼런스 머리 너비로 등방 정규화. 높이는 왜곡하지 않아 잔여 차이가 존재.
측면 검은 눈을 별도 추가하고 링을 볼로 바꾸었으므로 정면 얼굴은 동일하지 않음.
기존 정면 보존과 레퍼런스 얼굴 구조의 동시 달성은 아직 승인 필요.
머리 뒤쪽/턱, 귀, 몸통의 원본 대비 차이는 남아 있음. 완전 일치로 판단하지 않음.
외형 후보이며 운영 적용, 리깅, 모션, 다른 캐릭터 변경 없음.
