구현한 범위
- 귀 3종(고양이/토끼/둥근 귀), 꼬리 2종/없음, 몸 길이/너비, 귀 크기.
- 같은 rig.mjs가 대기/정면 보행/앉기와 다운로드 HTML을 렌더링.
- 머리 이미지의 가로세로 비율 고정. 귀는 머리 기준점 상속.
- 두 팔/두 발만 배치. 몸 길이에 따라 머리/어깨 연결점 이동.
- 발바닥 높이 366 고정; 보행 중 한쪽 발을 들 때 반대쪽은 접지.
- 앉기 끝은 유지; 발바닥 젤리는 sole 파츠로 표시.
- 별도 localStorage 키 ppolpet-parts-workshop-v1 저장/불러오기.
- 버전 있는 JSON 가져오기/내보내기. 잘못된 파일/범위 방어.
- 현재 설정 + PNG + 좌표 + 동일 렌더러를 포함하는 HTML 다운로드.

아직 아닌 것
- 기존 3/4 걷기/엎드리기/인사/보기/표정과 다른 다섯 캐릭터 연결은 미구현.
- 보행은 정면 파츠의 제자리 동작. 월드 이동/3/4 보행 리타겟팅 미구현.
- 실제 서비스 공방, .ppol, Electron 앱에 연결하지 않음.
- HTML은 오프라인 브라우저 재생본. 데스크톱 설치 파일/시메지 팩이 아님.
- 파츠 분리용 신규 아트는 승인본과 비슷하게 제작한 외형 후보이며 픽셀 동일본 아님.
- 임의 업로드 그림/무제한 체형/부위별 색 마스크 미지원.
