검수에서 발견: v6의 첫 두 자세 사이 손끝이 가슴에서 코 높이로 즉시 이동.
돌아오는 그림도 올라가는 자세와 달라 팔과 머리 모양이 튀는 인상.
코 외곽에 노란 돌기가 추가되어 작은 코와 중복되어 보임.

수정: 손끝 최대 높이를 턱 아래로 낮춤. 짧은 팔에 맞춰 가슴→조금 들기→반쯤→짧게 뻗기 순서.
앞쪽 팔은 가슴에 남고, 뒷팔만 움직임. 얼굴 전경/팔 후경 및 분홍 젤리 유지.
큰 노란 외곽 돌기 제거, 기존 작은 코 하나만 남김.
첫4자세를 0,1,2,3,3,2,1,0 순서로 재생. 실제 고유 자세4개 / 재생8단계.
그림 전체를 흔들거나 얼굴을 잘라 붙이지 않음. 중간 자세 사이의 연속 보간은 사용하지 않음.
전체프레임 같은 배율, 앞쪽 발바닥 기준 정렬. 원본 이미지의 픽셀동일성은 보장하지 않음.
