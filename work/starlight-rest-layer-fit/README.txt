사용자가 생성 후보를 반려하여, 원본 시트의 엎드리기 픽셀을 유지하는 방식으로 전환.
assets/reference.png 원본 보존. assets/source-layers.svg와 layer-*.svg는 같은 원본을 마스크로 분리한 코드 기반 조립본.
build-layers.py는 연결 영역을 분석하여 외곽 경계와 SVG 마스크를 생성한다. 원본 RGB를 다시 그리거나 변형하지 않는다.

눈·코를 숨기면 피부 패치도 함께 비므로 이 레이어 파일을 아직 독립 이동 리그로 사용하면 안 된다.
현재 정지 자세만 복원. 새 전환 프레임 및 모션은 제작하지 않았다.
원본/조립본/50% 겹침 및 부위별 표시를 검수 페이지에서 제공.
