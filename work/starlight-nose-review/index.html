코와 외곽선의 부착 관계

위와 동일한 렌더에 코 중심 가이드를 표시했습니다. 점 자체는 모델 파츠가 아닙니다.

검수 요점

  • 기존 측면 코는 경도와 높이를 따로 이동시켜 실제 코끝과 어긋났습니다. 후보는 머리 메시의 앞끝을 탐색해 부착 UV를 고정합니다.
  • 코만 덧붙이는 대신 앞중앙의 짧은 곡면을 다듬었습니다. 별도 코 돌기나 평면 파츠를 추가하지 않았습니다.
  • 머리의 X·Y 정점, 눈·귀와 체형은 보존합니다. 정면에서 코의 높이와 앞중앙의 명암은 소폭 달라질 수 있어 비교 대상으로 남겼습니다.
  • 75°~90°에서 코가 별도로 옆으로 이동하지 않습니다. 135° 이후 가려지는 것은 실제 곡면의 가림입니다.
