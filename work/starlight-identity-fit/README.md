# 정면 링 눈 우선 후보

기존 renderer, presets는 무수정 보존. 운영 반영 아님.
검수 URL: http://127.0.0.1:8766/starlight-identity-fit/

별도 검은 눈 추가는 45도에서 두 번째 눈처럼 보여 제외했다.
사용자가 허용한 '눈을 압축한 측면' 방향: 기존 링 눈 UV를 유지하고 링 바깥선에 0.012 모델 단위의 고정된 입체 가장자리를 생성했다. 각도별 이미지 교체/카메라 의존 가시성 없음.
코는 기존 정면 코 높이에서 실제 앞중앙 곡면 끝에 얕게 맞물리는 캡이다. 이전 캔버스 코는 제거해 중복 방지.
머리 X/Y, 귀, 몸통, 팔, 발, 꼬리는 변경하지 않는다. 앞중앙 Z 곡면만 수정.
0/45/75/90/135/180 비교와 실제 연속 회전/드래그 제공.

제한: 측면이 레퍼런스의 독립된 검은 타원 눈과 동일하지 않다. 정면 코 형태/앞중앙 명암 및 45도 눈 가장자리 차이는 남는다. 시각적 승인 대기이며 완전 보존/완전 일치로 주장하지 않는다.
